# Learning log

One short entry per working day, **in your own words**. Five minutes, even if it's three bullet points. By week 9 this is the raw material for the case study, the README and your interview answers.

## How

- Copy [template.md](template.md) to `YYYY-MM-DD.md` (e.g. `2026-09-29.md`).
- Write it yourself. Claude Code will prompt you at the end of a session but won't write it for you.
- Be honest about confusion: "What confused me" is the most useful section when you come back to it.
- Keep private details out: this folder is committed to a public repository.
