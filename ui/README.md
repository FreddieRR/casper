# Web UI

A deliberately minimal, mobile-friendly page: a question box, a streamed answer and clickable sources. It is reached from your phone over Tailscale and talks to the API with its own API key.

**Built in:** Week 3, Day 15 (keep it under an afternoon). Polished for phone use on Day 30 (add-to-home-screen, sensible font sizes).

**Decision pending (ADR):** plain HTML + HTMX, or something you already know such as Angular. Consider what you want to learn and how much front-end you want to maintain.

**Definition of done:** you can ask a question from your phone, watch the answer stream in and tap a source to see where it came from.
