# Grafana

Dashboards for Casper. Dashboards are built in the Grafana UI, then **exported as JSON into this folder** so they are version-controlled and can be provisioned automatically.

**Built in:** Week 7, Day 33.

**Planned dashboard:** the four golden signals (latency including time-to-first-token, traffic, errors, saturation), route mix (local vs cloud), tokens and cost per day, and GPU utilisation, VRAM and temperature.
